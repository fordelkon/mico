# Mico Frontend

Apply the project's [styling contract](../../../docs/styling.md) and the [UI package conventions](../../../packages/ui/README.md) for shared components.

For Claude-style layout or interaction decisions, fetch [Open Claude UI documentation](https://openclaudeui.com/docs) and only the sections needed for the current decision. Keep this as an on-demand link; do not copy the documentation into local context or fetch it for unrelated frontend work. The community reference does not override project tokens, accessibility, or the user's chosen design.
